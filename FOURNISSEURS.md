## 2. 📊 OUTILS MARKETING À CONFIGURER

### Google Analytics 4 (gratuit)
1. Va sur https://analytics.google.com
2. Connecte-toi avec naturesurvi@gmail.com
3. Crée une propriété "NatureSurvi"
4. Récupère ton **ID de mesure** (format : G-XXXXXXXXXX)
5. → Je l'intègre dans le code du site

### Meta Pixel / Facebook (gratuit)
1. Va sur https://business.facebook.com
2. Crée un compte Business pour NatureSurvi
3. Va dans Gestionnaire d'événements → Pixels
4. Crée un pixel et récupère le **Pixel ID** (nombre à 15-16 chiffres)
5. → Je l'intègre dans le code du site

### Newsletter — Brevo / ex-Sendinblue (gratuit jusqu'à 300 mails/jour)
1. Va sur https://www.brevo.com
2. Inscris-toi avec naturesurvi@gmail.com
3. Crée une liste de contacts "Newsletter NatureSurvi"
4. Récupère ta **clé API** dans Paramètres → SMTP & API
5. → Je connecte le formulaire newsletter du site

### Bonus recommandés (plus tard)
- **Google Search Console** (SEO gratuit) : https://search.google.com/search-console
- **Hotjar** (heatmaps gratuit) : https://www.hotjar.com
- **Mailchimp** (alternative newsletter) : https://mailchimp.com

## 3. 🌐 HÉBERGEMENT — Plan d'action

### Option recommandée : Netlify (gratuit)
1. Crée un compte GitHub : https://github.com/signup
2. Je pousse le code du site sur GitHub
3. Je connecte le repo à Netlify → site en ligne en 2 min
4. URL gratuite : naturesurvi.netlify.app
5. Plus tard : domaine personnalisé naturesurvi.fr (~8€/an chez OVH)

### Domaine naturesurvi.fr
