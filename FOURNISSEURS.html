2. 📊 OUTILS MARKETING À CONFIGURER

Google Analytics 4 (gratuit)

  1. Va sur analytics.google.com
  2. Connecte-toi avec naturesurvi@gmail.com
  3. Crée une propriété "NatureSurvi"
  4. Récupère ton ID de mesure (format : G-XXXXXXXXXX)
  5. → Envoie-le moi, je l'intègre dans le code du site

Meta Pixel / Facebook (gratuit)

  1. Va sur business.facebook.com
  2. Crée un compte Business pour NatureSurvi
  3. Va dans Gestionnaire d'événements → Pixels
  4. Crée un pixel et récupère le Pixel ID (nombre à 15-16 chiffres)
  5. → Envoie-le moi, je l'intègre dans le code du site

Newsletter — Brevo / ex-Sendinblue (gratuit, 300 mails/jour)

  1. Va sur brevo.com
  2. Inscris-toi avec naturesurvi@gmail.com
  3. Crée une liste de contacts "Newsletter NatureSurvi"
  4. Récupère ta clé API dans Paramètres → SMTP & API
  5. → Envoie-la moi, je connecte le formulaire newsletter
